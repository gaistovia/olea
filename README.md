# OLEA — Fine Dining & Wine House
### A GA Istovia Demo Studio Concept Project

**Industry:** Luxury Restaurant / Fine Dining Hospitality
**Type:** Concept / Showcase Project (fictional brand, built for demonstration purposes)

---

## Overview

OLEA is a flagship concept website created to demonstrate GA Istovia's approach to premium hospitality branding: a fictional Michelin‑calibre restaurant on the Athens Riviera, built around a single olive grove, a 4,000‑bottle cellar, and a chef with real culinary provenance. The goal of the demo is to show what a five‑star restaurant's digital presence should feel like — spacious, editorial, and conversion‑driven — without ever looking like a template.

## Brand Concept

- **Name:** OLEA (from *olea europaea*, the olive tree)
- **Positioning:** Mediterranean fine dining rooted in provenance and seasonality
- **Voice:** Warm, precise, unhurried — confident without being loud
- **Palette:** Marble White `#FBF9F5`, Warm Linen `#F4EFE6`, Champagne Gold `#C9A24B`, Deep Charcoal `#211E17`, Olive `#57624A`, Soft Beige `#E9DFCC`
- **Typography:** Fraunces (display serif) paired with Manrope (body / UI)

## Features

- Cinematic hero with staggered text‑reveal animation and scroll indicator
- Sticky glass‑morphism navigation with mobile drawer menu
- Full digital menu across 9 categories with dietary tags, plus a styled QR‑code menu panel
- Live reservation form with validation, availability indicator, and animated success state
- Chef storytelling section with awards and philosophy
- Six signature‑experience cards with mouse‑tilt interaction
- Masonry photo gallery with keyboard‑navigable lightbox
- Auto‑scrolling testimonials carousel with manual controls
- Animated statistics counters (guests served, awards, wine labels, etc.)
- Events calendar, FAQ accordion, private dining grid, and location/contact panel with embedded map
- Floating WhatsApp reservation button, back‑to‑top control, and cookie consent banner
- SEO: Open Graph & Twitter Card tags, canonical URL, Restaurant / FAQ / Breadcrumb JSON‑LD schema, semantic HTML, descriptive alt text
- Fully responsive from mobile through desktop; respects `prefers-reduced-motion`

## Technologies Used

- HTML5 (semantic structure, JSON‑LD schema)
- CSS3 (custom properties/design tokens, Grid, Flexbox, backdrop‑filter glass effects)
- Vanilla JavaScript (no frameworks) — IntersectionObserver for scroll reveals and counters
- Google Fonts (Fraunces, Manrope)
